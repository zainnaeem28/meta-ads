A product defect is written as an `it.fails` case (`openDefect`): the suite stays green while it is open and turns red the day the product is fixed, which forces the marker out. A contract gap is a waived matrix cell: the cell has a test that asserts what the product does instead, its name carries `[waived <ID>]`, and `scripts/ci/api-matrix.mjs` refuses a waiver whose ID is not in this file. None of these is fixed here: the allowed paths of TASK-065 are the suite, the gate script and this folder. Each needs a correction ticket from the Orchestrator.

## Reached only by a race

`last_admin` (API-101, 103, 104) cannot be reached one request at a time: the caller is an active administrator, so there are always two. It is reached when two administrators suspend each other at once and the second request passes the guard before the first commits; `admin-denials.conformance.test.ts` holds the first request at its target row to make the order certain, and proves one answer is 200 and the other 422 `last_admin` with one active administrator left.

The 503 of every operation is proved here with the rate-limit store down (a database failure is 503, never a pass-through).
