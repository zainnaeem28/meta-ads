# TASK-031 evidence
`platform/egress`: allow-listed https fetch on undici. DNS is resolved once, every answer is checked (private, loopback, link-local, metadata, IPv4-mapped IPv6, NAT64, 6to4, unique-local) and the connection is pinned to that answer, so a rebinding second answer is never used. Redirects are followed only to the same host over https (3 hops); any other target is refused. Size (declared and streamed) and time bounds, content-type check, no URL from a caller (the adapter builds the URL; IP literals, credentials, other ports and unlisted hosts are refused). The module has no logger: errors name the cause and host only, never a path, query or body.
