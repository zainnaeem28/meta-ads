The worker, MinIO, provider stubs and FFmpeg are not exercised: FLOW-06 reads and navigates, it generates nothing.
- Steps (screenshots `screenshots/<step>-390.png` and `-1440.png`, axe reports in `axe/`, zero violations at WCAG 2.2 AA):

- Paths covered: back, cancel, error (500 with retry, 404 unavailable), session expiry (before load and mid-use 401 with return path), permission (anonymous to sign-in, real api 401), keyboard (search box, campaign link by Enter).
