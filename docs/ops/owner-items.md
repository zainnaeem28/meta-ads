Every row below was applied completely and stays configurable; none held up the build and none is a placeholder. A row marked **default applied (autonomous)** is an agent's application of the register's recommended default: it appears in the go-live evidence and the owner confirms or changes it. Product gaps are the Orchestrator's separate list and never appear here.

Proof that needs a contract, a licence, a real account or a licensed person (signed vendor terms, the licensed advertising and privacy review, the Clerk and provider tenants, the GitHub plan, the production domain) stays an owner item. The code around each is finished; what the owner adds to deploy is in `docs/ops/release.md` and `README.md` ("Deployment-ready status").
